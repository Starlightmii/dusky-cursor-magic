══ 1. 4-POINT SPARKLE SPRITE (the ✦ star) — canonical formula (Steinrucken "Star(uv, flare)", verified godotshaders.com/shader/starfield-parallax-shader + /starfield-angled):
  d = length(uv)                    # uv centered on star, in star-radius units
  m  = 0.02 / d                     # gaussian-ish core falloff
  # 4-point cross: rays along axes
  rays  = max(0.0, 1.0 - abs(uv.x * uv.y * 10000.0))
  m   += rays * flare               # flare ~ 0.5..1.0
  # diagonal pair: rotate 45 deg, SAME formula, 0.3 weight
  uv  = rot(uv, PI/4)
  rays = max(0.0, 1.0 - abs(uv.x * uv.y * 10000.0))
  m   += rays * 0.3 * flare
  m   *= smoothstep(1.0, 0.2, d)    # window 1.0 -> 0.2 radius cutoff
NUMPY PORT for stamp(): the ray term = max(0, 1 - K*|x*y|) is separable — evaluate on the star's bbox grid (already windowed); K=10000 in uv-units ≈ K*8e-4 per canvas px² at size≈1. Tune: rays axis K_x=10000, diag K=10000*0.3. Diagonal length ratio 0.3-0.4 of main spikes. Add spin: rotate bbox by star.rot before evaluating (you already have spin*age).

══ 3. TWINKLE SYNC (phase-lock then desync — you already have sin(t*2.6+ang*3); refine):
  Per-star: sin(age * tw * TAU) with tw ∈ 1.5-2.6 (you have it) — per-star frequencies UNIFORM in [1.5, 2.6] not gauss — uniform reads as sparkle noise, gauss as breathing.
  GLOBAL sync wave: 0.30 * sin(t * 2.6 + ang * 3.0) — that's the "pulse as one" (all burst stars launched same t0 share the wave). Desync comes naturally: life 0.55-0.75 vs shed stars life 0.55-0.95 + freq spread.
  Freq range sanity: 2.6 rad/s = 0.41 Hz global pulse; per-star 1.5-2.6 Hz (tw*TAU ~ 9.4-16.3 rad/s is too fast — actual: tw is cycles/sec after TAU mult, so 1.5-2.6 Hz flicker ≈ film sparkle rate; Godot starfield uses twinkle 1.0 with sin(iTime*0.3*twinkle + n*48.123) — 0.3 rad/s base * random phase 48.123*hash).
  Steinrucken's exact twinkle: size_t = size * (sin(iTime*0.3*twinkle + n*48.123)*0.5+1.0) — the *0.5+1 remaps sin to [0.5,1.5] so stars PULSE SIZE 50-150%, never vanish. Use for size modulation: size * (1 + 0.5*sin(age*tw*TAU)) — brighter AND bigger together (additive alpha alone looks dim-only).
  SHED stars (trail): golden-angle direction t*2.39996 % TAU (you have — correct phyllotaxis), speed 30-90 px/s, life 0.55-0.95, drift 0.5-1.6 rad/s orbit (your ang2 = ang + drift*age is the "galaxy rotation").

══ 4. GALAXY FEEL (orbital drift):
  Spiral-arm shear (Köppen Milky-Way model, verified): arms = logarithmic spirals, angular offset per radius: θ(r) = θ0 + b*ln(r); differential rotation Ω ~ 1/r (inner faster). For a 300px aura: arm_phase = 1.2*ln(1 + r/40px) — stars at 2× radius lag ~0.8 rad in angle — that shear IS the galaxy look.
  Advection rate: drift ∈ [0.5, 1.6] rad/s (yours) ≈ 8-26°/s — reads as majestic, not spin. Add shear: ang2 = ang + drift*age + 1.2*ln(1+r_px/40) so outer stars trail behind = spiral arms form from any burst.
  Curl for trail wiggle: add sin(age*3 + ang*2)*0.15 to ang2 — cheap fake curl.

# Each asset is a multi-frame GIF converted from the animated Fluent emoji
set (APNG) published at https://github.com/microsoft/fluentui-emoji-animated
(MIT license, see https://github.com/microsoft/fluentui-emoji-animated/blob/main/LICENSE).
Conversion: every 2nd frame kept, max side 256 (PIL LANCZOS), transparency
preserved. Source APNGs are 256x256 already; no upscaling.
